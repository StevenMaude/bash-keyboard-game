⚠️ Browser compatibility

  • Ctrl+W closes the browser tab — it cannot be intercepted by any web page. Use Alt+Backspace instead; it does exactly the same thing (kill word backward).
  • Ctrl+T may open a new browser tab. The game intercepts it where possible, but you may need to return to this tab. Challenges that use it are marked with ⚠️.
  • Ctrl+N / Ctrl+W / Ctrl+T are browser-reserved on all platforms and are noted in affected challenge hints.
